# 연극영화과 대학 길찾기 (수도권)

현재 위치(기본값: 용인시 죽전역) 기준으로 수도권 연극영화과 개설 대학까지의
자차 / 대중교통 / 도보 거리·시간을 비교하고, 대학별 학과·입학 정보를 조회하는
지도 기반 웹 애플리케이션입니다.

- **스택**: Vite + React + Tailwind CSS + Leaflet (react-leaflet, OpenStreetMap)
- **지도 타일**: OpenStreetMap(일반) / Esri World Imagery(위성) — API 키 불필요
- **경로/지오코딩**: Kakao Mobility(자동차 실도로 경로) + Kakao Local(지오코딩) +
  ODsay(대중교통, 선택) REST API 연동. 키가 없거나 호출이 실패하면 자동으로
  직선거리 기반 추정치로 대체됩니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속. (프로덕션 빌드: `npm run build`, 미리보기: `npm run preview`)

## API 키 설정 (실제 경로 검색 활성화)

키가 없어도 앱은 정상 동작하지만(추정치 기반), 실제 도로 거리/시간·실제
경로선을 보려면 아래 키가 필요합니다.

### 1) Kakao REST API 키 (자동차 경로 + 출발지 검색)

1. [Kakao Developers](https://developers.kakao.com)에서 애플리케이션을 생성하고
   **요약 정보 > REST API 키**를 복사합니다.
2. **제품 설정**에서 카카오맵 / 카카오모빌리티 사용 설정을 켭니다.
3. **앱 설정 > 플랫폼 > Web**에 접속 도메인을 등록합니다 (개발: `http://localhost:5173`,
   배포 시 실제 도메인).
4. `.env.example`을 복사해 `.env`(또는 `.env.local`)로 저장하고 키를 입력합니다.

```bash
cp .env.example .env
```

```
VITE_KAKAO_REST_KEY=발급받은_REST_API_키
```

5. 개발 서버를 재시작합니다(`npm run dev`).

### 2) ODsay API 키 (선택 — 실제 대중교통 경로)

Kakao Mobility는 **자동차 길찾기만** 제공하고 지하철/버스 경로는 제공하지
않습니다. 실제 대중교통(환승 포함) 경로가 필요하면 [ODsay](https://lab.odsay.com)에서
무료 API 키를 발급받아 `.env`에 추가하세요.

```
VITE_ODSAY_API_KEY=발급받은_ODsay_API_키
```

키가 없으면 대중교통은 계속 추정치로 표시됩니다(앱이 깨지지 않습니다).

### ⚠️ CORS와 Vite 프록시

Kakao Mobility(`apis-navi.kakaomobility.com`)와 ODsay는 **서버 전용 API**라 브라우저에서
직접 호출하면 도메인을 등록해도 CORS로 차단됩니다. 이를 우회하기 위해
`npm run dev`로 실행하는 개발 서버는 `vite.config.js`의 프록시
(`/kakao-navi`, `/kakao-local`, `/odsay`)를 통해 대신 요청을 전달합니다.

- **개발(`npm run dev`)**: 프록시 덕분에 별도 설정 없이 바로 동작합니다.
- **운영 배포(`npm run build` 결과물)**: Vite 개발 서버 프록시가 없으므로, 이
  요청들을 대신 전달해줄 **자체 백엔드/서버리스 프록시**가 필요합니다(키를
  서버에만 두는 것이 보안상으로도 안전합니다). 현재 코드는 `import.meta.env.DEV`
  여부로 프록시 경로/실제 도메인을 자동 전환하도록 되어 있어(`src/utils/kakao.js`,
  `src/utils/odsay.js`), 배포 시 동일한 경로(`/kakao-navi` 등)로 응답하는 프록시
  서버만 앞단에 두면 코드 수정 없이 그대로 동작합니다.

### 키 적용 범위

| 항목 | 키 있음 | 키 없음(또는 호출 실패) |
| --- | --- | --- |
| 출발지 검색(지오코딩) | Kakao Local 키워드 검색으로 실제 지명 검색 | 내장 프리셋(죽전역, 강남역 등)만 인식 |
| 자차 거리/시간/경로선 | Kakao Mobility 실제 도로 거리·시간, 지도에 실제 도로 경로선 표시 | 직선거리 기반 추정치, 지도에는 직선 점선 표시 |
| 대중교통 거리/시간/경로선 | ODsay 실제 지하철/버스 환승 경로 (키 설정 시) | 추정치, 직선 점선 표시 |
| 도보 거리/시간 | 추정치 (도보 전용 공개 API 없음) | 추정치 |

각 카드/상세 모달의 자차·대중교통 항목에 실제 데이터일 때 `●` 표시가 붙어
현재 보고 있는 값이 실측치인지 추정치인지 알 수 있습니다.

## 지도/카드에서 자차·대중교통·도보 전환하기

하단 카드의 자차/대중교통/도보 박스를 클릭하면 그 이동수단이 지도 위
경로선(파란=자차, 초록=대중교통, 주황=도보)으로 전환되어 표시됩니다. 실제
경로(API 실측)가 있으면 실선, 없으면(추정치) 점선으로 구분됩니다.

## "길찾기 시작" 버튼이 실제로 안내하지 않는 문제

Google Maps는 **한국 내 자동차 턴바이턴 길찾기를 제공하지 않습니다**(지도 반출
규제로 인해 국내 서비스가 비활성화되어 있음). 그래서 이전 버전에서는 지도만
뜨고 실제 경로 안내가 진행되지 않았습니다. 현재는 [길찾기 시작] 버튼과 상세
모달의 링크가 **카카오맵**(`map.kakao.com`)으로 열리도록 변경되어, 카카오맵
자체 UI에서 자동차/대중교통/도보 탭을 눌러 실제 국내 경로 안내를 받을 수
있습니다(`src/utils/kakao.js`의 `buildKakaoMapRouteUrl`, 별도 API 키 불필요).

## 주요 기능

1. **출발지 설정**: 상단 검색창에 지명을 입력해 출발지를 변경할 수 있습니다.
   Kakao 키가 있으면 실제 장소 검색이, 없으면 `죽전역`, `강남역`, `서울역`,
   `수원역`, `분당역`, `인천공항`, `판교역` 등 프리셋 지명이 동작합니다.
2. **대학 검색/선택**: 상단 검색창에서 대학명을 검색해 직접 추가할 수 있습니다
   (개별 검색 추가는 최대 15개, 아래 지역 필터는 이 제한과 무관). 선택된 대학은
   칩(태그) 형태로 표시되며 클릭으로 해제 가능합니다.
3. **대학 분류 체계** (`src/data/universities.json`, `src/utils/tiers.js`):
   - **🎓 1차 필수** (숫자 대신 학사모 아이콘, 항상 기본 표시): 한예종, 중앙대,
     세종대, 단국대, 용인대, 경기대, 가천대, 서울예대, 동아방송예술대
   - **1 (서울 · 4년제)**: 한양대, 건국대, 국민대, 성균관대, 동국대, 명지대,
     서경대
   - **2 (서울 · 전문대)**: 백석예대, 명지전문대, 인덕대
   - **3 (경기 남부)**: 경희대(국제캠퍼스), 수원대, 성결대, 국제대,
     명지대(자연캠퍼스), 안양대, 평택대
   - **4 (경기 동부)**: 예원예술대(양주)
   - **5 (인천)**: 인하대, 인천대
   - 여자대학교(여대)는 목록에서 제외했습니다.
   - 지도 상단 중앙의 필터 바에는 **🎓(1차 필수) + 1~5** 버튼이 모두 있어,
     누르면 해당 그룹 대학이 지도·하단 카드에 한 번에 추가/제거되고(다시 누르면
     숨김), 버튼 옆에 지금 표시 중인 그룹명이 함께 표시됩니다(예: "2026년입시
     지원예상 대학교 · 서울권 4년제 대학"). 라벨 색상은 tier 1~5는 해당 버튼과
     같은 글자색, 🎓은 주황 배경+검정 글자 배지로 구분됩니다. 🎓 그룹은
     기본으로 켜져 있습니다.
   - 상단 헤더의 "아이콘: 비비드/파스텔/다크/브라이트" 셀렉트로 마커 색상
     테마를 바꿀 수 있습니다. 테마와 무관하게 그룹마다 서로 다른 색상 계열
     (🎓 호박색 / 1 파랑 / 2 빨강 / 3 초록 / 4 주황 / 5 보라)을 사용해 지도에서
     한눈에 구분되도록 했습니다.
   - 각 그룹 내 대학은 인지도(지명도) 순으로 정렬되어 있습니다.
   - "연기 실기보다 영상 기획·연출·제작에 특화된 학과"(오산대 공연축제콘텐츠과,
     여주대 방송영상미디어과, 한신대 디지털영상문화콘텐츠학과)는 연극영화과
     성격에 맞지 않아 목록에서 제외했습니다.
   - 참고: 서울예술대학교는 서울 남산에 "동랑예술센터(남산캠퍼스)"라는 부속
     시설이 있지만, 이는 공연·전시·워크숍용 공간일 뿐 재학 학과가 있는
     정규 캠퍼스가 아니라서 별도 항목으로 추가하지 않았습니다.
   - 참고: 사용자 제보로 추가 조사한 결과 **경희대학교**의 연극영화학과는
     서울캠퍼스가 아니라 **국제캠퍼스(용인 기흥구)** 소속임을 확인해 반영했고,
     **청운대학교** 연극예술학과는 인천캠퍼스가 아니라 **충남 홍성캠퍼스**에만
     있어(수도권 밖) 목록에 추가하지 않았습니다. **예원예술대학교**는 안성이
     아니라 **경기 양주(경기드림캠퍼스)** 소재로 확인되어 경기 동부로 분류했습니다.
4. **실제 경로 기반 거리/시간**: 자차는 Kakao Mobility, 대중교통은 ODsay(키 설정 시)로
   실제 이동 거리·시간을 조회합니다. 도보 이동이 현실적인 5km 이내인 경우에만
   도보 항목이 추가로 표시되며, 2km 이내는 초록색으로 강조됩니다.
5. **카드에서 이동수단 전환**: 자차/대중교통/도보 박스를 눌러 지도 경로선을
   해당 수단으로 전환할 수 있습니다.
6. **카드 클릭 시 지도 확대**: 하단 카드를 클릭하면 출발지와 해당 대학이 모두
   보이도록 지도가 자동으로 확대/이동합니다.
7. **입시 상세 통계**: 상세 정보 모달에 수시:정시 비율, 실기/학생부 반영 비율,
   최근 경쟁률, 내신 영향/비고를 표시합니다. **29개교 전체**가 웹 조사로 확인한
   실제 수치를 담고 있으며, 확인되지 않은 항목은 "확인 필요"/"공개 정보 없음"
   으로 정직하게 표시했습니다. 예술계열 전형은 매년 반영 비율·전형 방법이
   자주 바뀌고 합격자 평균 내신은 대부분 대학이 비공개이므로, 반드시 각 대학
   최신 모집요강으로 재확인하세요.
8. **1차 필수 대학 이름 라벨**: 지도에서 🎓(1차 필수) 대학은 마커
   위에 학교명이 항상 표시됩니다.
8. **대학 상세 정보**: 마커 팝업 또는 카드의 [상세 정보/입학 정보] 버튼으로
   대학 개요, 학과 특징, 입학 정보 요약을 확인할 수 있습니다.
9. **즐겨찾기**: ★ 버튼으로 즐겨찾기를 등록/해제하고, 헤더의 "즐겨찾기"
   버튼으로 필터링할 수 있습니다.
10. **길찾기 시작**: 카카오맵으로 실제 자동차/대중교통/도보 길찾기를 새 탭에서 엽니다.
11. **지도 컨트롤**: 확대(+)/축소(−), 출발지로 이동(📍), 일반/위성 지도 전환.

## 프로젝트 구조

```
├── .env.example                # Kakao/ODsay API 키 설정 템플릿
├── vite.config.js               # dev 서버 CORS 프록시 (/kakao-navi, /kakao-local, /odsay)
├── index.html
├── src/
│   ├── main.jsx              # 엔트리 포인트
│   ├── App.jsx                # 전역 상태 관리(출발지/선택 대학/이동수단 등) 및 레이아웃 조립
│   ├── index.css              # Tailwind 진입 + Leaflet 관련 전역 스타일
│   ├── hooks/
│   │   └── useRoutes.js       # origin↔대학 경로 조회 훅 (낙관적 추정치 → 실제 API 결과로 갱신)
│   ├── components/
│   │   ├── Header.jsx                  # 출발지 검색, 대학 검색/선택 칩, 아이콘 테마
│   │   ├── MapView.jsx                 # react-leaflet 지도, 마커, 모드별 실제/추정 경로선
│   │   ├── MapControls.jsx             # 확대/축소, 내 위치, 일반/위성 뷰 전환
│   │   ├── TierFilterBar.jsx           # 지도 상단 1~5 지역별 빠른 표시/숨기기 버튼
│   │   ├── BottomSheet.jsx             # 하단 대학 카드 슬라이더 (모드 전환 가능)
│   │   └── UniversityDetailModal.jsx   # 대학 상세/입학 정보 + 카카오맵 링크
│   ├── data/
│   │   └── universities.json  # 수도권 연극영화과 개설 대학 데이터 (tier 1~5, 지역별)
│   └── utils/
│       ├── kakao.js    # Kakao Local(지오코딩)/Mobility(자동차 길찾기)/카카오맵 딥링크
│       ├── odsay.js    # ODsay 대중교통 길찾기 REST 래퍼(선택)
│       ├── geocode.js  # 지명 → 좌표 변환 (Kakao API 우선, 프리셋 fallback)
│       ├── routing.js  # 거리·시간 계산 (Kakao/ODsay 실경로 + 캐시, walk는 추정치)
│       ├── icons.js    # tier 1~5 마커 아이콘(divIcon) 생성, 색상 테마(팔레트)
│       └── tiers.js    # tier 1~5 라벨/배지 색상 공통 정의
```

## 참고 사항

- `src/data/universities.json`의 대학 개요/학과 특징/입학 정보 및 좌표는
